Cause: `apps/web/components/dashboard-shell.tsx` awaits `auth()` then `consultantCompany.count` then `<NotificationsDropdown />` before the page shell renders. Wrap `NotificationsDropdown` in `<Suspense>` and move the pending-invitation count into a Suspense boundary too so the sidebar renders immediately. Expected: cold ~600 ms → ~350-400 ms.
